# Super Trunfo Cartas:

O programa simula um jogo de cartas comparando duas cidades brasileiras.
Determina qual carta vence baseado em um atributo específico (População)

Cadastro de cartas

Carta 1: São Paulo (SP)
Carta 2: Rio de Janeiro (RJ)
Atributos armazenados: Estado, código, nome da cidade, população, área, PIB e pontos turísticos

Cálculos feitos de forma automática:

Densidade Populacional: População ÷ Área (hab/km²)
PIB per Capita: PIB ÷ População (convertendo bilhões para reais)

Mostra todos os dados das duas cartas de forma organizada
Inclui tanto os dados originais quanto os calculados

Comparação:
Atributo escolhido: População (definido no código)
Regra: Maior população vence
Estrutura: if/else para determinar o vencedor

Tipos de Dados Utilizados

char[]: Para textos (estado, código, nome da cidade)
int: Para números inteiros (população, pontos turísticos)
float: Para números decimais (área, PIB, cálculos)

Saída do Programa

Dados completos das duas cartas
Comparação detalhada mostrando os valores
Resultado final indicando qual carta venceu
Diferença entre os valores comparados

Funcionalidades Implementadas: 

Cadastro de duas cartas,cálculos automáticos (densidade e PIB per capita), comparação de um atributo específico, determinação do vencedor, tratamento de empate, saída formatada e clara.
