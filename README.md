 ========================================================================
 SUPER TRUNFO - DESAFIO FINAL
 ========================================================================
  
 Programa: Sistema avançado de comparação de cartas Super Trunfo
 Autor: Desenvolvido para o desafio de programação em C
 Data: 2025

 Descrição:
 Este programa implementa um jogo de Super Trunfo onde o usuário pode
 comparar dois países usando DOIS atributos diferentes simultaneamente.
  
Funcionalidades principais:
Menus dinâmicos que se adaptam às escolhas do usuário
Comparação individual e combinada de atributos
Interface colorida com códigos ANSI
Validação robusta de entradas
Tratamento especial para densidade demográfica
